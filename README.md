## 🚀 Cách Dùng

Chỉ cần mở file `gift-surprise.html` trên trình duyệt — không cần cài đặt, không cần server, không cần internet.

Hoặc deploy lên **Netlify Drop** trong 30 giây:
1. Vào [app.netlify.com/drop](https://app.netlify.com/drop)
2. Kéo thả file `gift-surprise.html` vào
3. Lấy link gửi cho người nhận 💝
